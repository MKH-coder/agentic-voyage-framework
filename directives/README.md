# Directives (Layer 1: What to do)

This directory houses Standard Operating Procedures (SOPs) for the repository.

## Anatomy of a Directive

1. **Title & Objective**: Clear statement of the task's end state.
2. **Prerequisites & Inputs**: Configuration, schema, and credentials needed.
3. **Deterministic Steps**: Step-by-step instructions referencing scripts in `execution/`.
4. **Verification**: How to validate completion.
5. **Edge Cases**: Lessons learned and caveats discovered during execution.
